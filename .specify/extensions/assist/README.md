# speckit-assist-ask

A [Spec Kit](https://github.com/github/spec-kit) extension that assists in onboarding developers into SDD projects using specs directory and project constitution as knowledge base

## How It Works

`/speckit.assist.ask` lets developers query the project's specifications and constitution:

- Ask about features and implementation details
- Query architectural decisions and rationale
- Get onboarding guidance based on actual project patterns

## Requirements 

- Spec Kit >= 0.9.0 (Mandatory)
- Git >= 2.0.0
